Start the Vite development server so the user can preview the app locally.

Steps:
1. Run `npm install` if `node_modules` does not exist yet.
2. Run `npm run dev`.
3. Confirm the server is listening (look for "Local: http://localhost:5173" in the output).
4. Tell the user the app is running and share the local URL.

If the port is already in use, Vite will automatically pick the next available port — report whichever URL it prints.
