# Vercel App Starter

A scaffolding project for building and deploying web apps to Vercel. Describe what you want to build, and the app gets created and published for you.

## Stack

- React 19 + TypeScript
- Vite 6 (dev server + build)
- CSS Modules for styling
- Vercel deployment with SPA routing pre-configured

## Getting started

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check + production build → dist/
```
